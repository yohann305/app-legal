# app-legal

Public pages for Yohann Taieb apps, hosted on GitHub Pages: an app directory, one landing page per app, and the privacy, terms and support documents those apps already use.

The directory and landing pages use the approved factual copy. They are not a ranking. Optional paid features and local prices stay in the App Store and inside each app.
